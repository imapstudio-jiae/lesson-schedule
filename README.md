# 🎵 음악 학원 / 스튜디오 전용 실시간 레슨 시간표 웹앱

음악 학원 및 개인 스튜디오에서 원장님과 선생님이 복잡한 로그인/회원가입 없이 실시간으로 레슨 일정, 운영 공지, 그리고 하단 메모 카드를 공유·관리할 수 있는 React + Firebase Firestore 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **100% 한국어 인터페이스 & 모던 대시보드 디자인**
   - 따뜻하고 고급스러운 웜 오렌지 & 파스텔 테마 적용
   - 눈이 편안한 그리드 및 Pretendard 폰트 기반 직관적인 UI

2. **자동 월 선택 및 달력 네비게이션**
   - 현재 연월(2026년 10월 등) 자동 기본 표시
   - `[< 이전달]`, `[다음달 >]`, `[연도/월 선택 드롭다운]`, `[이번달로 바로가기]` 지원
   - 월이 바뀌면 해당 월(`YYYY-MM`)의 시간표 및 공지/메모 데이터가 독립적으로 저장·로드

3. **상단 운영 안내문 (실시간 수정 & 공유)**
   - 선택된 연월(예: `2026년 10월 스튜디오 운영 안내사항`) 자동 표시
   - `수정` 버튼 클릭 시 인라인으로 공지문 편집 및 즉시 저장
   - 수정 즉시 다른 접속자 화면에도 실시간 반영

4. **메인 시간표 (Grid 형태)**
   - **7개 열(Columns)**: `시간`, `월요일`, `화요일`, `수요일`, `목요일`, `금요일`, `토요일`
   - **행(Rows)**: 오전 `06:00`부터 오후 `20:00`까지 30분 단위 슬롯
   - 셀 클릭 시 모달 팝업:
     - 학생 이름
     - 수업 시간/형태 (40분 정규, 성인그룹 40분, 30분 기초, 60분 입시, 직접 입력)
     - 색상 태그 선택 (오렌지, 코랄, 앰버, 세이지 그린, 스카이 블루, 라벤더 등)
     - 개별 메모 / 진도 사항
     - 등록, 수정, 삭제 지원

5. **하단 동적 메모 카드 영역 (완전 편집 가능)**
   - 기본 4개 카드 제공:
     1. 📌 `[특수 일정 / 최수연]`
     2. 🎸 `[학생 밴드 연습곡]`
     3. 🎹 `[듀오 / 선생님과 연습]`
     4. ✨ `[이벤트 및 기타 특이사항]`
   - 각 카드별 제목 수정, 색상 변경, 카드 삭제 기능
   - 각 줄 단위 체크리스트 항목 추가, 완료 체크, 삭제 기능
   - `[+ 새 메모 카드 추가]` 버튼으로 카드 개수 자유자재 확장

6. **💰 레슨비 정산 탭 (2026-11 신규)**
   - 상단 탭에서 `📅 시간표` ↔ `💰 레슨비 정산`을 오가며 사용 (시간표 기능·데이터는 그대로)
   - 월별 독립 저장: Supabase `studio_schedule` 테이블에 `fees_2026-11`, `fees_2026-12` 형태의 키로 저장/불러오기
   - 학생별 단가·수업 형태·메모 인라인 수정, 입금 상태 토글(미확인 → 입금완료 → 면제)과 입금일 자동/수동 입력
   - 필터(전체/미확인/입금완료/면제/예약제·보강), 검색, `카톡 요약 복사`, 모바일 카드형 레이아웃
   - 배분 비율(기본 지애 60% · 인웅쌤 40%)과 홈페이지 개발·관리비(100,000원), 학생 관리비(수강생 수 × 10,000원)를 월별로 저장
   - `+ 추가 / 차감 항목`으로 대상(지애 님/인웅쌤)과 금액(±)을 직접 넣어 그 달 최종 정산 합계에 바로 반영
   - `카톡 요약 복사` 문구에 레슨비 60:40 배분과 추가·차감 항목(홈페이지 개발·관리비·학생 관리비·사용자 항목)을 모두 반영한 **최종 정산 합계**가 함께 들어감
   - **진행 회차(4회권) 카운터**: 월 4회가 다 안 채워져 다음 달로 넘어가는 학생(예: 최수연)은 학생 행·모바일 카드에서 `0/4회` `+`/`−` `남은 N회`·`4회 완료`로 기록. 목표 회차 기본 4회(수정 모달에서 변경), 일반 학생은 `회차 관리` 토글이나 수정 모달의 `횟수 차감제` 체크로 켜고 끔

7. **Firebase Firestore 실시간 동기화 (`onSnapshot`)**
   - 별도 회원가입 없이 같은 스튜디오 룸 ID 또는 프로젝트 연결로 1초 만에 실시간 동기화
   - 웹앱 상단 `[Firebase 설정]` 버튼을 통해 브라우저에서 바로 Firebase 웹 앱 설정을 붙여넣어 연동 가능
   - 설정 전이어도 브라우저 로컬 저장소 및 탭 간 자동 실시간 동기화(BroadcastChannel) 지원
   - `[인쇄 / PDF]` 버튼으로 시간표 출력 최적화 스타일 지원

## 🚀 실행 방법

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

브라우저에서 `http://localhost:5173/` 접속하여 사용하실 수 있습니다.

## 🔐 스튜디오 잠금 (비밀번호 게이트)

- 앱을 열면 먼저 `🔒 IMAP Studio` 잠금 화면이 뜨고, 비밀번호를 맞혀야 시간표·레슨비 정산 화면이 나타납니다. 잠금 해제 전에는 시간표 데이터를 그리지 않고 Supabase/Firestore 조회도 하지 않습니다(`AppLockGate.jsx`가 `App` 자체를 마운트하지 않음).
- 비밀번호는 코드에 평문으로 두지 않고 `src/lockAuth.js`의 `PASSWORD_SHA256` 해시와 비교합니다. 비밀번호를 바꾸려면 새 비밀번호의 SHA-256 값을 이 상수에 넣으면 됩니다.
- 잠금 해제 상태는 브라우저 `localStorage`(`imap_studio_unlocked`)에 저장되어 같은 기기에서는 새로고침·재방문 시 다시 묻지 않고, 헤더 우측의 `🔒 잠금` 버튼으로 언제든 다시 잠글 수 있습니다.
- 관련 파일: `src/lockAuth.js`, `src/AppLockGate.jsx`, `src/components/LockScreen.jsx`, `src/lock.css`

## 🔒 Firebase Firestore 실시간 연동 방법

1. [Firebase Console](https://console.firebase.google.com/)에서 프로젝트 생성 후 웹 앱 (`</>`)을 등록합니다.
2. Firestore Database를 생성하고 **규칙(Rules)** 탭에서 인증 없이 두 분이 공유할 수 있도록 설정합니다:
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /studios/{studio}/months/{month} {
         allow read, write: if true;
       }
     }
   }
   ```
3. 웹앱 상단의 **[Firebase 설정]** 버튼을 누르고 콘솔에서 복사한 `firebaseConfig` 객체를 붙여넣은 뒤 **[연동 저장 및 동기화]**를 누르면 끝납니다!
