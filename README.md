# 🎵 음악 학원 / 스튜디오 전용 실시간 레슨 시간표 웹앱

음악 학원 및 개인 스튜디오에서 원장님과 선생님이 복잡한 로그인/회원가입 없이 실시간으로 레슨 일정, 운영 공지, 그리고 하단 메모 카드를 공유·관리할 수 있는 React + Firebase Firestore 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **100% 한국어 인터페이스 & 모던 대시보드 디자인**
   - 따뜻하고 고급스러운 웜 오렌지 & 파스텔 테마 적용
   - 눈이 편안한 그리드 및 Pretendard 폰트 기반 직관적인 UI

2. **자동 월 선택 및 달력 네비게이션**
   - 현재 연월(2026년 10월 등) 자동 기본 표시
   - `[< 이전달]`, `[다음달 >]`, `[연도/월 선택 드롭다운]`, `[이번달로 바로가기]` 지원
   - 월이 바뀌면 해당 월(`YYYY-MM`)의 시간표 및 공지/메모 데이터가 독립적으로 저장·로드

3. **상단 운영 안내문 (실시간 수정 & 공유)**
   - 선택된 연월(예: `2026년 10월 스튜디오 운영 안내사항`) 자동 표시
   - `수정` 버튼 클릭 시 인라인으로 공지문 편집 및 즉시 저장
   - 수정 즉시 다른 접속자 화면에도 실시간 반영

4. **메인 시간표 (Grid 형태)**
   - **7개 열(Columns)**: `시간`, `월요일`, `화요일`, `수요일`, `목요일`, `금요일`, `토요일`
   - **행(Rows)**: 오전 `06:00`부터 오후 `20:00`까지 30분 단위 슬롯
   - 셀 클릭 시 모달 팝업:
     - 학생 이름
     - 수업 시간/형태 (40분 정규, 성인그룹 40분, 30분 기초, 60분 입시, 직접 입력)
     - 색상 태그 선택 (오렌지, 코랄, 앰버, 세이지 그린, 스카이 블루, 라벤더 등)
     - 개별 메모 / 진도 사항
     - 등록, 수정, 삭제 지원

5. **하단 동적 메모 카드 영역 (완전 편집 가능)**
   - 기본 4개 카드 제공:
     1. 📌 `[특수 일정 / 최수연]`
     2. 🎸 `[학생 밴드 연습곡]`
     3. 🎹 `[듀오 / 선생님과 연습]`
     4. ✨ `[이벤트 및 기타 특이사항]`
   - 각 카드별 제목 수정, 색상 변경, 카드 삭제 기능
   - 각 줄 단위 체크리스트 항목 추가, 완료 체크, 삭제 기능
   - `[+ 새 메모 카드 추가]` 버튼으로 카드 개수 자유자재 확장

6. **Firebase Firestore 실시간 동기화 (`onSnapshot`)**
   - 별도 회원가입 없이 같은 스튜디오 룸 ID 또는 프로젝트 연결로 1초 만에 실시간 동기화
   - 웹앱 상단 `[Firebase 설정]` 버튼을 통해 브라우저에서 바로 Firebase 웹 앱 설정을 붙여넣어 연동 가능
   - 설정 전이어도 브라우저 로컬 저장소 및 탭 간 자동 실시간 동기화(BroadcastChannel) 지원
   - `[인쇄 / PDF]` 버튼으로 시간표 출력 최적화 스타일 지원

## 🚀 실행 방법

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

브라우저에서 `http://localhost:5173/` 접속하여 사용하실 수 있습니다.

## 🔒 Firebase Firestore 실시간 연동 방법

1. [Firebase Console](https://console.firebase.google.com/)에서 프로젝트 생성 후 웹 앱 (`</>`)을 등록합니다.
2. Firestore Database를 생성하고 **규칙(Rules)** 탭에서 인증 없이 두 분이 공유할 수 있도록 설정합니다:
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /studios/{studio}/months/{month} {
         allow read, write: if true;
       }
     }
   }
   ```
3. 웹앱 상단의 **[Firebase 설정]** 버튼을 누르고 콘솔에서 복사한 `firebaseConfig` 객체를 붙여넣은 뒤 **[연동 저장 및 동기화]**를 누르면 끝납니다!
